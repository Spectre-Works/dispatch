# Brand Assets

[DISPATCH Bridge](dispatch-bridge.svg) is the source mark.
The [square icon](dispatch-icon.svg) is shared by the dashboard, favicon,
and StartOS package. Regenerate it after updating the mark.

```sh
python3 tools/generate_dispatch_icon.py
```

The [README header](dispatch-header.svg) pairs the Bridge emblem with the full DISPATCH
name in upright Chakra Petch Bold capitals. The lettering is outlined so the
lockup renders consistently without a font download.

The [social preview](dispatch-social-preview.png) is a 1280 × 640 PNG.
Use it as the custom social preview in the GitHub repository settings.
