# Controller dashboard

[index.html](index.html) contains the controller's HTML, CSS, and JavaScript.
The ESP-IDF build embeds the page and a compressed copy. Edit it here, then
build and flash the application to exercise it with real controller routes.
The browser renders status and sends commands. The controller evaluates the plan
and acts on equipment.
[Controller build and flash](../../docs/development.md#build-and-flash)

Exercise changed flows at desktop and phone widths. For status, check live
and stale readings. For plan and equipment edits, check the saved state and
the outlet actions in Preview. Follow the [operator guide](../../docs/operations.md)
for current dashboard paths.
